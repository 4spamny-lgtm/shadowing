# 유튜브 쉐도잉

유튜브 영상의 영어 자막을 문장 단위로 나눠서, 한 문장씩 듣고 따라 말하는(쉐도잉) 연습을 하는 개인용 웹앱입니다. 안드로이드 폰과 아이패드에서 홈 화면 앱처럼 쓸 수 있습니다.

- **PC (Windows)**: `prep.py`로 유튜브 자막을 받아 문장 단위 JSON으로 만듭니다.
- **폰 / 아이패드**: GitHub Pages에 올린 `index.html`로 쉐도잉 연습을 합니다.

## 폴더 구성

```
SHADOWING\
  index.html      웹앱 (화면 전체가 이 파일 하나)
  prep.py         자막 전처리 스크립트 (PC에서 실행)
  add.bat         영상 추가 + GitHub 업로드를 한 번에
  README.md       이 문서
  .gitignore      GitHub에 올리지 않을 파일 목록
  videos\
    index.json    영상 목록 (웹앱이 읽음)
    영상ID.json   영상별 문장 목록과 단어 타이밍
```

## 처음 설치 (PC, 한 번만)

PowerShell에서 실행합니다. 설치 후에는 PowerShell을 닫았다가 다시 여세요.

```
winget install Python.Python.3.12
winget install --id=DenoLand.Deno
winget install --id Git.Git -e
```

필요한 파이썬 패키지:

```
pip install -U "yt-dlp[default]"
```

자막에 문장 부호가 없는 영상까지 잘 나누려면 무료 문장 부호 모델도 설치합니다 (처음 실행 때 약 2GB 다운로드).

```
pip install deepmultilingualpunctuation
```

## 영상 추가하기

### 방법 1: add.bat (추천)

`add.bat`을 더블클릭하고 유튜브 주소를 붙여넣은 뒤 Enter를 누르면, 자막 처리부터 GitHub 업로드까지 한 번에 끝납니다. 주소 여러 개는 띄어쓰기로 구분합니다. 1~2분 뒤 폰과 아이패드에서 앱을 다시 열면 새 영상이 보입니다.

주소 없이 Enter만 누르면 자막 처리는 건너뛰고, 폴더에서 바뀐 파일(예: 고친 `index.html`, 편집해서 내보낸 JSON)만 업로드합니다.

### 방법 2: 직접 실행

폴더에서 터미널을 열고 실행합니다. 주소는 꼭 따옴표로 감쌉니다.

```
python prep.py "https://www.youtube.com/watch?v=영상ID"
python prep.py "주소1" "주소2"
python prep.py "https://www.youtube.com/playlist?list=재생목록ID"
```

| 옵션 | 설명 |
|---|---|
| `--force` | 이미 처리한 영상도 다시 처리 |
| `--seg local` | (기본) 자막에 문장 부호가 없으면 로컬 모델로 문장 나누기 |
| `--seg rules` | 모델 없이 말이 끊기는 구간 기준으로만 나누기 (빠름, 품질 낮음) |
| `--seg claude` | Claude API 사용 (환경 변수 `ANTHROPIC_API_KEY` 필요) |

자막에 문장 부호가 이미 들어 있으면(최근 유튜브 자동 자막은 대부분 그렇습니다) 모델 없이 그 부호를 그대로 씁니다.

## 배포 (GitHub Pages)

저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 설정하면 `https://내아이디.github.io/저장소이름/` 주소로 열립니다. 무료로 쓰려면 저장소가 공개(public)여야 하므로, 주소를 아는 사람은 누구나 볼 수 있다는 점을 알아두세요.

## 폰 · 아이패드에서 쓰기

**홈 화면에 추가**

- 안드로이드 (크롬): ⋮ 메뉴 → 홈 화면에 추가
- 아이패드 (사파리): 공유 버튼 → 홈 화면에 추가

처음 재생할 때 반응이 없으면 영상을 한 번 직접 눌러 주세요.

**기본 사용법**

- 목록에서 문장을 누르면 그 문장만 재생됩니다.
- **재생**을 누르면 문장 듣기 → 따라 말하기 시간 → 다음 문장 순서로 자동 진행됩니다.
- 그냥 영상을 재생하면 현재 문장이 목록에서 따라 움직입니다.

**툴바 버튼** (누를 때마다 값이 바뀜)

| 버튼 | 설명 |
|---|---|
| 자동 넘김 | 끄면 현재 문장만 반복 횟수만큼 듣고 멈춤 |
| 자막 보기 / 가리기 / 처음만 가리기 | 가린 문장은 눌러서 잠깐 볼 수 있음. "처음만 가리기"는 한 번 들은 뒤에 보여줌 |
| 반복 N회 | 한 문장을 몇 번 반복할지 (1, 2, 3, 5회) |
| 속도 | 0.5x, 0.75x, 1x, 1.25x |

**설정**에서는 따라 말하기 시간(문장 길이의 몇 배), 문장 앞뒤 여유 시간, 큰 글씨, 문장 편집 모드를 바꿀 수 있습니다. 문장 끝이 잘리거나 다음 문장이 살짝 들리면 "문장 뒤 여유"를 조절하세요.

**키보드 단축키** (PC, 키보드를 연결한 아이패드)

| 키 | 동작 |
|---|---|
| Space | 재생 / 정지 |
| ← / → | 이전 / 다음 문장 |
| ↓ 또는 R | 현재 문장 다시 듣기 |
| H | 가린 자막 잠깐 보기 |

## 문장 편집

설정에서 **문장 편집 모드**를 켜면 현재 문장 아래에 편집 버튼이 나타납니다.

- 앞과 합치기 / 뒤와 합치기
- 나누기: 단어 목록에서 나눌 위치를 누름
- 시작 / 끝 시간 0.1초씩 조절 (조절할 때마다 바로 들려줌)

편집 내용, 설정, 이어보기 위치는 **그 기기의 브라우저에만** 저장됩니다. 다른 기기에도 반영하려면 설정의 **JSON 내보내기**로 받은 파일을 PC의 `videos` 폴더에 같은 이름으로 덮어쓰고 `add.bat`을 실행해 업로드하세요. **원래대로**를 누르면 그 기기에서 편집한 내용이 지워집니다.

## 문장 나누기 기준 조정

`prep.py` 위쪽의 값을 바꾸면 됩니다. 바꾼 뒤에는 `--force`로 다시 처리하세요.

| 값 | 기본 | 의미 |
|---|---|---|
| `MAX_WORDS` | 28 | 이보다 긴 문장은 쉼표나 말이 끊기는 곳에서 나눔 |
| `MIN_WORDS` | 3 | 이보다 짧은 문장은 옆 문장과 합침 |
| `MERGE_GAP` | 1.0 | 짧은 문장을 합칠 때 허용하는 최대 간격(초) |
| `PAUSE_GAP` | 0.5 | 규칙 기반에서 문장 경계로 볼 쉼(초) |

## PC에서 미리 테스트하기

`index.html`을 더블클릭하면 영상 목록을 못 읽습니다. 폴더에서 아래를 실행한 뒤 브라우저로 `http://localhost:8000`을 여세요. 끝낼 때는 Ctrl+C.

```
python -m http.server 8000
```

## 문제 해결

| 증상 | 해결 |
|---|---|
| `can't open file ... prep.py` | 파일 이름이 `prep_py.py`나 `prep.py.txt`로 저장됐는지 확인 (`dir`로 확인 후 `ren`으로 이름 변경) |
| 자막 받기 실패, "Sign in to confirm you're not a bot" | 잠시 후 다시 시도하거나 `pip install -U "yt-dlp[default]"`로 업데이트 |
| "영어 자막이 없는 영상" | 영어 자막(자동 자막 포함)이 없는 영상은 처리할 수 없음 |
| 앱에서 "다른 사이트에서 재생이 막혀 있어요" | 업로더가 외부 재생을 막은 영상이라 이 앱에서는 재생 불가 |
| 새 영상이 목록에 안 보임 | 업로드 후 1~2분 기다린 뒤 앱을 완전히 닫았다가 다시 열기 |
| 단축키가 안 먹음 | 설정 창이 열려 있지 않은지 확인, 앱 화면의 빈 곳을 한 번 클릭 |
| `git push` 거부 (이메일 관련) | `git config --global user.email`을 GitHub의 noreply 주소로 설정 (GitHub → Settings → Emails에서 확인) |
